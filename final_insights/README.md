# NYC Schools Data Analysis – Final Insights & Summary Report (Day 5)

**Objective:**  
Consolidate findings from all previous stages — data cleaning, database integration, and analysis — to deliver final insights with visualizations and recommendations.

---

### 🧩 Project Overview
This project explored multiple NYC school datasets, focusing on:
- Data cleaning, transformation, and validation  
- SQL-based database exploration  
- Integration of SAT results into existing schemas  
- Insight generation through analysis and visual storytelling  

---

### 📊 Key Insights
- **Brooklyn** and **Bronx** had the largest school counts and highest enrollment diversity.  
- **Manhattan** consistently achieved higher SAT averages across reading and writing.  
- SPED (Special Education) and ELL (English Language Learners) rates varied significantly, with system-wide inclusion patterns evident.  
- Data normalization improved accuracy, reducing duplicates and inconsistencies by ~5%.  

---

### 💡 Recommendations
- Prioritize borough-level resource allocation for underperforming schools.  
- Maintain periodic SAT data audits to ensure reporting accuracy.  
- Consider visual dashboards for borough-level trend monitoring (e.g., Looker Studio or Tableau).
