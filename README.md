# 🏫 NYC Schools Data Analysis

**Author:** Robert Sesazi  
**Project Duration:** Days 1–5 (Masterschool Data Analysis Track)

---

## 📘 Overview
This project analyzes SAT performance and demographic data from over 400 public schools across New York City.  
It follows a structured five-day pipeline — from raw data cleaning to SQL integration and visualization — to uncover borough-level academic insights and equity patterns.

---

## 🔍 Project Phases
**Day 1 – Data Cleaning:**  
Removed duplicates, standardized column names, handled missing values.  

**Day 2 – Data Exploration:**  
Explored key statistics for participation, ELL %, SPED %, and performance indicators.  

**Day 3 – SQL Integration:**  
Loaded datasets into PostgreSQL (Neon) and performed joins across school tables.  

**Day 4 – Incident & Demographic Analysis:**  
Analyzed safety incidents, enrollment, and borough-wise variations.  

**Day 5 – Final Insights & Visualization:**  
Created summary datasets (`borough_performance.csv`) and visualized SAT results by borough using Python (pandas + matplotlib).

---

## 📊 Key Insights
- **Manhattan** achieved the highest average SAT Math score (520).  
- **Staten Island** followed closely (510) with strong consistency despite fewer schools.  
- **Bronx and Brooklyn** had larger school counts but slightly lower averages, suggesting overcrowding or uneven resource distribution.  
- High **ELL (English Language Learner)** percentages in Manhattan & Bronx indicate areas needing additional linguistic support.
